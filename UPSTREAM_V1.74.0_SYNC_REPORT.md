## Product boundary

BSCHEKER, reachability and GEO remain supported only by the official Upstream
Bot backend. Custom Cabinet contains no route, menu, permission, setting, API
client, locale, fixture or operator asset for that feature family. The normal
`npm test` gate includes the executable exclusion guard.

## Adapted vertical slices

- Default best-value tariff and period selection across purchase, renewal, gift
  and landing flows, with highlighted and selected states preserved together.
- Recurring-provider capability flags stop unsupported SBP/Lava probing while
  responses from older Bot versions without flags retain the previous fallback.
- Authenticated non-admin screen and click activity is batched safely; URL query
  strings, input values, admin routes and ignored elements are not collected.
- Admin tariffs consume `panel_tag`, trial duration, zero-price periods and
  clearable highlighted-period contracts.
- Admin user summary consumes deleted-user totals; Activity uses readable
  Mini App labels; user and partner detail routes remount on identifier changes.
- Active subscription cards contain long tariff names and switch from device
  dots to a compact bar for large device limits.
- Full Sync wording is aligned with the exact Bot behavior.
