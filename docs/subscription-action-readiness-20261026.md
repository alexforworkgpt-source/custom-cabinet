# Ранний показ действий подписки — 2026-10-26

## Результат

При известном положительном safe-integer ID управление запрашивает подписку и
purchase-options параллельно. Для прежнего входа без ID сохраняется ожидание
подписки. URL, параметры `subscription_id`, ключи кэша, staleTime0 и обязательное
обновление при входе сохранены; получения условий недостаточно для показа данных
неподтверждённой/отсутствующей подписки.

После появления карточки основное действие сразу видно как недоступную кнопку
с индикатором. До подтверждения режима продаж у paid classic без tariff_id
показываются «Загрузка… / Проверяем условия…», без предположения о маршруте.
Известные trial/legacy/tariff подписи и кэшированные условия сохраняют свой вид.
Ссылка появляется только после окончания успешной проверки условий и подписки.
Ошибки, Retry, отсутствие записи и прежний запрет активного daily renewal сохранены.

`PurchaseCTAPresentation` использует существующие HoverBorderGradient/Button и
Spinner. Pending — native disabled button с aria-busy, без href; ready остаётся
прежней ссылкой. Место и подписи при переходе между состояниями сохраняются.
Новых CSS-классов, зависимостей и финансовой логики нет. Новая нейтральная подпись
переведена в RU/EN/FA/ZH.

На Dashboard без подписки «Выберите тариф» отображается до ответа trial API.
Предложение пробного периода появляется ниже кнопки, поэтому её положение
не меняется после позднего ответа. Активация trial и её ограничения не менялись.

## TDD

Каждый следующий сценарий добавлялся после успешной предыдущей правки:

| Проверка | RED | GREEN |
| --- | --- | --- |
| Условия запрашиваются до ответа subscription | запроса нет при удержании subscription | параллельный GET с subscription_id42; один запрос |
| Trial action виден, но недоступен до условий | кнопка отсутствует | disabled button; затем прежний purchase URL с ID |
| Возврат с кэшем ждёт обе свежие записи | после options открывается ссылка по старой подписке | действие заблокировано до subscription; новый trial ведёт в покупку с ID |
| Неизвестный sales_mode не выдаётся за известный | показано неподтверждённое действие | нейтральная подпись; подтверждённая подпись при обновлении |
| Покупка независима от trial availability | ссылка скрыта до trial ответа | ссылка доступна; поздний trial не двигает её |

Проверки API начинаются после появления заголовка страницы, чтобы время загрузки
JS-модулей не подменяло проверку последовательности запросов. Задержки ответов
управляются deferred gates, assertions/timeouts не ослаблялись.

Существующие mobile geometry tests дополнительно выявили13.5px сдвиг из-за
типографики базового Button. Локальные `font-normal leading-normal` возвращают
прежнюю геометрию презентации; стандартный допуск4px сохранён.
