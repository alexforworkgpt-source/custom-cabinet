# Локальный API-мокап: 28 сценариев пользователя и полный режим

Эта инструкция нужна для интерактивной browser-проверки Custom Cabinet без
запущенного Upstream Bot. Мокап открывает отдельное окно Chromium, подменяет
Cabinet API безопасными локальными ответами и выдаёт тестовому пользователю
права `super_admin` с разрешением `*:*`.

**Основной путь для просьбы «запусти мокап с разными пользователями» — готовый
переключатель 28 состояний, описанный ниже.** Пункты1–14 проверены2026-10-20;
2026-10-21 добавлены и проверены пункты15–28 для скидок и предложений.
Старый полный helper и его специальные проверки
сохранены во второй части инструкции; искать или генерировать мокап заново
для обычного запуска не требуется.

## Прежний полный helper и специальные проверки

Следующие разделы сохраняют инструкцию для `.scratch/local-preview.mts`, включая
аудит кнопок и полный набор mock-функций. Для обычного запуска пользовательских
сценариев используй быстрый путь выше: он не требует `npx` или пакета `tsx`.

## Когда использовать

Используй этот режим, когда нужно вручную проверить пользовательские и
административные экраны Custom Cabinet на `127.0.0.1`. Для обычного
автоматического e2e-прогона по-прежнему используй `npm run test:e2e`.

Локальный помощник находится в `.scratch/local-preview.mts`. Каталог `.scratch/`
исключён из Git и относится только к текущему рабочему окружению. Перед запуском
убедись, что файл существует. Если его нет, не восстанавливай мок-ответы по
догадкам: используй `npm run test:e2e` или запроси актуальный локальный помощник.

## Что включено в полный режим

- тестовая роль `super_admin` и разрешение `*:*`;
- активная подписка, устройства, баланс и тарифы;
- способы пополнения и сохранённая карта;
- подключение Windows, Android и iPhone/iPad;
- реферальная программа;
- колесо удачи, подарки, конкурсы и опросы;
- безопасные тестовые ответы без записи в настоящий Upstream Bot;
- внешние и платёжные переходы только на тестовые адреса.

## Частые проблемы

### `ERR_CONNECTION_REFUSED`

Vite не запущен или уже завершился. Повтори первый шаг и дождись адреса
`http://127.0.0.1:5173/`, затем снова запусти мокап.

### Порт `5173` уже занят

Останови предыдущий локальный Vite и повтори запуск. Не меняй порт только в одной
команде: `.scratch/local-preview.mts` открывает фиксированный адрес
`http://127.0.0.1:5173/`.

### В профиле нет «Админки»

Убедись, что во второй команде задано `LOCAL_PREVIEW_FULL=1`. Базовый режим не
выдаёт права администратора.

### Открывается `/login`

Используется обычная вкладка браузера, а не Chromium, созданный локальным
помощником. Перезапусти второй шаг и работай в открывшемся отдельном окне.

### `npx --no-install` не находит `tsx`

Не разрешай `npx` скачивать пакет автоматически. Убедись, что зависимости
восстановлены через `npm ci` из текущего `package-lock.json`, после чего повтори
команду.

- Не заменяй тестовые ответы настоящими production-токенами или платёжными URL.
- Не используй мокап как доказательство совместимости с реальным Upstream Bot.
- Не добавляй `.scratch/`, скриншоты или локальные browser-данные в публичный
  commit или Release Bundle.
- Для staging/production-проверки следуй `LIVE_CHECK.md` и применимому Release
  процессу.
