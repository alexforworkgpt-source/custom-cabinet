# Issue Tracker

Tracker type: local Markdown.

Issues, PRDs, specifications and implementation tickets live under:

```text
.scratch/<feature>/
```

Each work item is a Markdown file with a short front matter block containing at
least `title`, `type` and `status`.

Canonical triage statuses are defined in `docs/agents/triage-labels.md`.

When a skill publishes an issue locally, it must return the exact file path.
Local issue files are working artifacts and are not a public Release source.

Pull requests are not an issue intake surface for this configuration.
