# Triage Labels

Use the canonical labels without aliases:

| Role | Label |
| --- | --- |
| Unclassified work | `needs-triage` |
| Missing information | `needs-info` |
| Ready for autonomous implementation | `ready-for-agent` |
| Requires human action or decision | `ready-for-human` |
| Intentionally rejected | `wontfix` |

For local Markdown issues, store the selected label in the `status` front matter
field.
